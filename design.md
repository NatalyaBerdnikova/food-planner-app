# Kitchen Stories — Design Code

Референс визуального и UX-языка приложения **Kitchen Stories** (iOS).  
Apple Design Award (2017), Google Material Design Award (2016).  
Цель файла: зафиксировать паттерны, которые можно сознательно переносить в Food Planner.

---

## 1. Суть бренда

Kitchen Stories продаёт не «каталог рецептов», а **ощущение готовки**: спокойствие, аппетит, уверенность «anyone can cook».

| Полюс | Как проявляется |
| --- | --- |
| Тёплый / эмоциональный | Еда на фото, мягкий свет, «домашняя» атмосфера |
| Молодой / живой | Волны (squiggles), насыщенные акценты, лайки, фиды |
| Надёжный / практичный | Чёткие теги времени и диеты, пошаговый cook-mode, списки покупок |

Дизайн всегда **photo-first**: UI — рамка вокруг еды, а не конкурирующий с ней слой.

---

## 2. Визуальная идентичность

### 2.1 Фотография

- Студийные кадры еды: крупный план, естественный свет, аппетитная текстура.
- Часто top-down или лёгкий угол 30–45°.
- Фон тарелки / стола чистый; минимум визуального шума.
- Видео того же качества — не «стоковые клипы», а продолжение фотоязыка.
- Карточка рецепта ≈ **картина**: изображение занимает 60–80% площади карточки.

### 2.2 Бренд-мотив: squiggles / волны

После ребрендинга символ — абстрактные волнистые линии (пар, лапша, глазурь, капуста — что угодно из сенсорного опыта еды).

Использование в UI:

- иконка приложения;
- пустые состояния, онбординг, иллюстрации;
- декоративные акценты на маркетинговых экранах;
- **не** поверх hero-фото рецепта (еда остаётся чистой).

### 2.3 Цвет

Палитра вдохновлена ингредиентами (не «технологичным» purple/blue):

| Роль | Характер | Примеры направлений |
| --- | --- | --- |
| Canvas | Светлый, нейтральный, почти белый / тёплый off-white | Чистый фон под фото |
| Primary accent | Насыщенный «съедобный» цвет | Корал / tomato / berry |
| Secondary | Мягкие ingredient-tones | Sourdough, olive, berry-blue |
| Text | Почти чёрный на светлом; secondary — серый средний | Высокий контраст для шагов |
| Tags / chips | Светлая заливка + цветной текст или outline | Время, vegan, difficulty |
| Like | Яркий акцент на иконке сердца / лайка | Социальный сигнал без шума |

Правило: **акцент редкий**. Большая часть экрана — белое + фото + типографика.

### 2.4 Типографика

- Современный humanist / neo-grotesque sans (не декоративный serif для UI).
- Заголовки рецептов: крупные, уверенные, 1–2 строки.
- Метаданные (время, калории, теги): secondary size, regular/medium.
- Шаги готовки: крупный readable body — экран должен читаться с расстояния руки у плиты.
- Иерархия жёсткая: Title → Meta row → Body → Captions. Без competing headlines.

### 2.5 Форма и глубина

- Скругления карточек: умеренные continuous corners (не «пилюли»).
- Тени мягкие, короткие — карточка «лежит на бумаге», не «парит в неоне».
- Разделители чаще whitespace, реже hairline.
- Полный bleed для hero на detail; на ленте — inset cards с ровным gutter.

## 3. Информационная архитектура (iPhone)

Типичная нижняя навигация (вариации по версиям):

1. **Discover / Home** — персональный фид, секции, карусели.
2. **Search** — поиск + фильтры (время, диета, кухня).
3. **Cookbooks / Saved** — коллекции и сохранённое.
4. **Shopping** — список покупок из рецептов.
5. **Profile** — настройки, предпочтения, подписка.

Онбординг: предпочтения (диета, любимые блюда) → персонализация фида (время суток, сезон, погода). Дизайн онбординга — полноэкранные фото + короткие вопросы, не формы Excel.

---

## 4. Ключевые экраны и паттерны

### 4.1 Home / Discover

- Вертикальный скролл секций: «For you», категории, seasonal, quick.
- Горизонтальные карусели карточек внутри секций.
- Секция = **один заголовок + одна идея**, без dashboard-сетки из виджетов.
- Карточка в ленте:
  - большое фото;
  - название;
  - ряд тегов (⏱ время, 🌱 vegan/veg, сложность);
  - лайк / социальный сигнал.

### 4.2 Recipe card

Минимальный набор:

```
┌─────────────────────────┐
│                         │
│      FOOD PHOTO         │
│                         │
├─────────────────────────┤
│ Recipe title            │
│ 25 min · Vegetarian     │
│ ♥ 1.2k                  │
└─────────────────────────┘
```

- Нет перегруза иконками.
- Теги — текст, не cryptic glyphs alone.
- Like обновлён после ребренда: заметный, но не доминирующий над фото.

### 4.3 Recipe detail

1. **Hero** — edge-to-edge фото (иногда видео preview).
2. Title + meta (время, порции, теги).
3. Короткое intro / story (editorial tone).
4. Ingredients — чеклист, масштабирование порций.
5. Steps — нумерованные шаги; у многих шагов своё фото.
6. CTA: Start cooking / Add to shopping / Save / Like.

Whitespace между блоками щедрый. Нет «панели статистики» в первом экране.

### 4.4 Cook mode (пошаговый режим)

Самый характерный KS-паттерн:

- Почти fullscreen шаг.
- Крупный номер шага + текст.
- Фото шага, если есть.
- Свайп / кнопки Next / Prev; минимум chrome.
- Таймеры там, где нужно — встроенные, не уводящие из контекста.
- Контраст и размер шрифта рассчитаны на «мокрые руки / дальняя плита».

### 4.5 Search & filters

- Поиск сверху.
- Chip-фильтры: время, диета, тип блюда.
- Результаты — та же recipe card, что в Discover (единый visual language).

### 4.6 Shopping list

- Чистый checklist.
- Группировка по категориям продуктов или по рецептам.
- Утилитарный экран: меньше photo-theatre, больше ясности.

## 5. Motion

- Переходы спокойные: fade + soft slide, не bounce-circus.
- Hero image может слегка parallax / scale при скролле.
- Like — короткий spring / scale на иконке.
- Смена шага в cook-mode — горизонтальный page-turn / slide.
- Reduce Motion: отключать декоративный parallax, оставлять смену контента.

Motion создаёт **присутствие и иерархию**, не шум.

---

## 6. Контент и тон

- Тексты короткие, дружелюбные, без кулинарного снобизма.
- Рецепт = история + инструкция.
- Теги честные: время готовки, dietary flags — обязательный UX-сигнал выбора.
- Социальность лёгкая: likes, community numbers — не лента комментариев как в соцсети.

---

## 7. Что **не** делать «как Kitchen Stories»

- Не закрывать еду бейджами, стикерами и floating promo-chips поверх hero.
- Не превращать home в dashboard (календарь + статистика + 5 виджетов в первом viewport).
- Не использовать холодный tech-gradient как главный вайб.
- Не мельчить карточки в плотную сетку 2×N без воздуха.
- Не конкурировать типографикой с фото (огромный display-serif поверх блюда).

## 8. Design tokens (ориентиры для переноса)

Не официальные токены KS, а **рабочие эквиваленты** для SwiftUI-референса:

```swift
// Canvas
canvas:              #FAFAF8 … #FFFFFF
elevatedCard:        #FFFFFF

// Accent (ingredient-inspired; подобрать одну доминанту)
accent:              coral / tomato / berry  // один primary
accentSoft:          accent @ 12% opacity

// Text
textPrimary:         #1A1A1A
textSecondary:       #6B6B6B

// Shape
cardRadius:          12…16 (continuous)
chipRadius:          8…10
contentPadding:      16
sectionSpacing:      24…32
cardImageAspect:     ~4:3 или 1:1 (стабильно в ленте)

// Elevation
cardShadow:          y: 2…8, blur: 12…24, opacity: 0.06…0.10
```

Типографика (семантика):

| Token | Размер / вес | Где |
| --- | --- | --- |
| `recipeTitle` | title2–title1, semibold | Карточка, detail |
| `sectionHeader` | title3, semibold | Секции Discover |
| `meta` | footnote / subheadline, medium | Время, теги |
| `stepBody` | body / title3, regular | Cook mode |
| `caption` | caption, regular | Secondary labels |

## 9. Компонентный чеклист (SwiftUI mental model)

| Компонент | Поведение |
| --- | --- |
| `RecipeCard` | Photo dominant + title + meta tags + like |
| `TagChip` | Время / diet / difficulty, low contrast fill |
| `SectionRail` | Header + horizontal ScrollView карточек |
| `RecipeHero` | Full-bleed image, title below or overlay с сильным scrim только для читаемости |
| `IngredientList` | Stepped servings, checkable rows |
| `CookStepPager` | Fullscreen steps, large type, next/prev |
| `LikeButton` | Accent heart, count optional |
| `EmptyState` | Squiggle/illustration + short copy + one CTA |

## 10. Как переносить в Food Planner

| Взять у Kitchen Stories | Сохранить в Food Planner |
| --- | --- |
| Photo-first карточки рецептов | Акцентная зелень / warm fill бренда приложения |
| Теги времени и диеты на карточке | Недельный план, nutrition targets |
| Воздух, секции-рельсы, спокойный motion | Планирование слотов еды |
| Чистый cook/detail hierarchy | Локальные данные и planner UX |
| Лайки / community numbers как лёгкий social proof | Без превращения в соцсеть |

Практическое правило:

1. **Discover / Library** — язык Kitchen Stories (еда и вдохновение).
2. **Week plan / Nutrition** — структура и цели планировщика; карточки блюд внутри слотов — KS-style.
3. Один accent из темы приложения; не копировать коралл KS буквально, если бренд уже зелёный.

---

## 11. Короткий audit-шаблон

Перед мержем UI-изменения спросить:

1. Первое, что видит глаз — еда или chrome?
2. Можно ли убрать рамку/тень/бейдж без потери смысла?
3. Есть ли у рецепта понятное время готовки на карточке?
4. Читается ли текст шага с вытянутой руки?
5. Не превратился ли первый экран в dashboard?

Если 1 = еда, 2–5 = да → вы в зоне Kitchen Stories.
