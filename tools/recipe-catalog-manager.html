Менеджер каталога рецептов

Создавайте рецепты как в приложении: название, ингредиенты по catalogKey, шаги, imageId (файл в RecipeImages/) или превью в JSON. Экспорт → recipes-catalog.json в проект iOS.

Каталог ингредиентов

Загрузите JSON из ingredient-catalog-manager ({ "version": 1, "products": [...] }). Без каталога нельзя подобрать ингредиенты и посчитать КБЖУ.

Рецепты — импорт / экспорт

Формат: { "version": 1, "recipes": [ { "id", "name", "imageId", "steps", "ingredients" } ] }. Совместим с импортом одного рецепта в приложении (RecipeImportService).
